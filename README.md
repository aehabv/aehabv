## A bit about me

I studied Computer Science at Capital University (formerly Helwan University), then did a 9-month Data Science diploma at ITI on a state scholarship. These days I work on data platforms, and in my free time I'm a bit obsessed with what's going on inside a model. Why did it say that? Can I trust it? I got hooked on explainable AI, and I've been reading about it ever since.

## Things I've built

I like taking things apart to see how they work, so most of these are about what happens under the hood.

| | Project | What happened |
|---|---|---|
| 📉 | [Gradient descent from scratch](https://github.com/aehabv/Building-Gradient-Descent-Methods-from-Scratch) | I wrote Momentum, NAG, AdaGrad, RMSProp, Adam and BFGS in plain NumPy to see what training really does. On a small regression problem BFGS got there in 43 steps. Adam needed 388. |
| 🗣️ | [Hate speech in Arabic tweets](https://github.com/aehabv/Hate-Speech-Detection-on-Arabic-Tweets) | Team project for the OSACT 2022 shared task. We fine-tuned MARBERT and got F1 scores of 88% for offensive language and 92% for hate speech. |
| 🏗️ | [Cement strength prediction](https://github.com/aehabv/Cement-Strength-Prediction-with-PySpark) | Linear regression, trees and gradient boosting in PySpark. The linear model hit a test RMSE of 7.65 MPa (R² 0.78). Age, cement and water mattered most. |
| 🕵️ | [Fake job posting detector](https://github.com/aehabv/Indeed-fake-job-posting-prediction) | Spotting scam listings when only 5% of the data is fraud. |
| 🎭 | [Face generation with a DCGAN](https://github.com/aehabv/Face-Generation-using-GANs) | A PyTorch GAN that learns to dream up faces from CelebA. |
| 📚 | [Arabic book search and Q&A](https://github.com/aehabv/Arabic-Book-Recommendation-and-Question-Answering-System) | Team project. We scraped a book site, cleaned and lemmatised the Arabic text, and predicted book categories with 73% accuracy. |

My graduation project at university was a skin cancer classifier trained on the ISIC 2020 dataset (95% accuracy, 96% F1).
